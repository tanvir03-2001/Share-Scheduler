# Facebook Auto Post Service

A modern, responsive Facebook automation service built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 🚀 **Modern UI/UX** - Clean, professional design with mobile responsiveness
- 📱 **Mobile First** - Fully responsive design that works on all devices
- 🎨 **Tailwind CSS** - Utility-first CSS framework for rapid development
- ⚡ **Next.js 14** - Latest Next.js with App Router and TypeScript
- 🔧 **TypeScript** - Full type safety and better developer experience
- 📊 **Analytics Ready** - Built-in components for tracking and insights
- 🎯 **SEO Optimized** - Proper meta tags and semantic HTML

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd facebook-auto-post-service
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
